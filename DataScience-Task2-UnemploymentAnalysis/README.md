# Unemployment Analysis with Python

## Project Overview

This project performs Exploratory Data Analysis (EDA) on unemployment
data from India. The analysis focuses on regional and temporal trends
in unemployment and examines the impact of the COVID-19 pandemic.

## Objective

The objective of this project is to analyze unemployment patterns
across different regions of India and understand changes in
unemployment over time.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset loading and inspection
- Missing value analysis
- Data cleaning and type conversion
- Region-wise average unemployment rate
- Month-wise unemployment trends
- Time-series analysis
- Top 10 regions with highest average unemployment rate
- Correlation heatmap
- Pre-COVID vs Post-COVID comparison
- COVID-19 unemployment analysis

## Dataset

The project uses the "Unemployment in India" dataset.

## Conclusion

The analysis provides insights into regional and temporal variations
in unemployment in India and shows changes in employment-related
indicators during the COVID-19 period.
